# ☕ Ezzick Coffee Theme for Obsidian

Тёплая кофейная тема для Obsidian, разработанная для комфортной долгой работы с заметками, структурированными базами знаний и списками задач. Поддерживает как тёмный, так и светлый режимы с выверенным контрастом.

---

## ✨ Ключевые особенности

- **Гармоничная кофейно-землистая палитра:** Мягкие бежево-кофейные оттенки в светлой теме и глубокие графитово-эспрессо тона в тёмной.
- **Двухколоночный блок свойств (Properties):** 
  - Компактный двухколоночный grid с аккуратным выравниванием ключей и значений.
  - Специальная обработка поля `aliases` — растягивается на всю ширину над колонками с автоматическим переносом значений (flex-wrap).
- **Стилизованные интерактивные чекбоксы:**
  - Векторные SVG-иконки для расширенного синтаксиса задач: `[?]`, `[!]`, `[*]`, `[-]`, `[>]`, `[<]`, `["]`, `[b]`, `[c]`, `[d]`, `[f]`, `[I]`, `[i]`, `[k]`, `[l]`, `[p]`, `[s]`, `[u]`, `[w]`, `[/]`, `[+]`.
  - Завершенные задачи аккуратно приглушаются без агрессивного перечеркивания текста.
- **Кастомные Callout-блоки:** Индивидуальные акценты и подобранные иконки для стандартных и расширенных типов заметок (`sprint`, `pin`, `sixdots`, `connect`, `base_line` и др.).
- **Оформление таблиц и списков:** 
  - Верхняя акцентная рамка и контрастная «кофейная» шапка таблицы.
  - Подсветка строк и ячеек при наведении курсора.
- **Нативная интеграция хайлайтов:** Тонкая настройка цветных маркеров под палитру темы через системный механизм Obsidian.

## 📥 Установка

### Ручная установка (через папку темы):

1. Скачайте файлы `theme.css` и `manifest.json`.
2. Перейдите в каталог вашего хранилища:
   `ВашеХранилище/.obsidian/themes/`
3. Создайте там папку `Ezzick Coffee` и положите внутрь скачанные файлы:
   ```text
   .obsidian/themes/Ezzick Coffee/
   ├── theme.css
   └── manifest.json

4. В Obsidian откройте **Настройки → Оформление → Тема** и выберите **Ezzick Coffee**.
